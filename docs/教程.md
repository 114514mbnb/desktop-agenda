## 1. 它是干什么的

两件事合在一块，常驻桌面右侧：

| | 说明 |
| --- | --- |
| **群通知** | 把 QQ 群里的通知变成带**时间/地点/人员/备注**的日程，自动去重，记忆一周 |
| **课程表** | 从文件识别课表（支持 WakeUp `.ics`、教务 PDF、网页、CSV 等格式），按节次时间展开到每一天 |

合起来就是"今天和未来一周要干什么"的一条时间线，钉在桌面上，不占地方也不挡操作。

**它不做什么**（先说清楚，免得期待错位）：
- 不读取 QQ 聊天记录。QQ 未提供开放接口，通知通过拖入文件或粘贴文本录入
- 不接触教务账号与密码。课表通过**文件**识别，无需登录
- 不联网。所有解析都在本机完成

## 2. 五分钟上手

### 第一步：打开

双击项目目录里的 `start-client.cmd`，或者桌面上的 **「桌面日程」** 快捷方式。

会出来两个窗口：

- **桌面日程 · 控制台** —— 主要操作界面（通知、课程表、上课时间、假期、设置）
- **今日日程** —— 常驻桌面右侧的面板，只看不改

### 第二步：把课表导进来

在控制台「课程表」页点击 **「从文件识别课表…」** → 选择课表文件 → 在确认窗口中核对 → 点击 **「确认导入」**。

详细说明见 [第 4 节](#4-把课表导进来)。

### 第三步：把通知加进来

在控制台「通知」页将群消息粘贴至输入框 → 约 1 秒后下方显示识别结果 → 点击 **「保存并刷新」**。

或者更快：**把消息文件直接拖到桌面面板上**。详细见 [第 5 节](#5-把群通知加进来四种方式)。

### 第四步：设成开机自启（可选）

```
tools\install.cmd       装开机自启 + 每天早上 7:30 自动整合
tools\uninstall.cmd     卸载（数据保留）
```

## 3. 桌面面板怎么用

面板就是右侧那条时间线。从头到脚：

```
┌─────────────────────────┐
│ 13:39                   │  ← 大时钟
│ 9月23日 周三 · 第 3 教学周  │  ← 日期 + 教学周
│ 下一项 2小时30分后 · 中国近… │  ← 最近的一项（蓝字）；进行中会变绿
├─────────────────────────┤
│ 今天 9/23 周三    3节课·1条通知 │  ← 每天一个分组头，右侧是当天数量
│ 08:00  ┃ 数学分析1      [课] │
│ 09:50  ┃ 中心校区 A-330·陈立│
│        ┃ 第1-2节            │
│ 12:00  ┃ 中秋国庆假期备案   │  ← 通知（左边橙色竖条）
│        ┃ 思想动态调研：…    │
│        ┃ 数学与统计学院2026级…群  │  ← 来源群
├─────────────────────────┤
│ 今天 3 节课 · 今日通知 1 条 · 一周共 14 项 │  ← 底部状态
│ 最近整合：2 分钟前                    ⚙ │  ← 右下角小齿轮＝设置
└─────────────────────────┘
```

### 能做的操作

| 操作 | 怎么做 |
| --- | --- |
| **翻页** | 鼠标滚轮；右侧那条细滚动条也能拖 |
| **移动面板** | 按住顶部标题区（时钟 / 日期 / 下一项）拖动 |
| **调整宽度** | 拖动右下角，或拖动右侧 / 下侧的隐藏边缘 |
| **查看全文** | **双击**某张卡片 → 弹出详情窗口（含长备注全文） |
| **处理某一条** | **右键**那张卡片 → 完成 / 改结束时间 / 复制 / 删除（见 [第 6 节](#6-处理单条日程右键)） |
| **打开设置** | 点右下角的 **⚙ 小齿轮** →「日程表设置…」（会叫出控制台并直接切到「设置」页） |
| **全局菜单** | 在面板**空白处**右键 |
| **打开客户端** | 齿轮菜单 →「打开客户端窗口」，或右键底部状态行 |
| **快速录通知** | 齿轮菜单或右键空白处 →「快速录入群消息…」 |
| **立即整合收件箱** | 齿轮菜单或右键空白处 →「立即整合群通知」 |
| **收起面板** | 齿轮菜单，或右键空白处 →「收起面板」/「收起 1 小时」 |
| **退出面板** | 右键空白处 →「退出面板」（**面板进程将结束**） |
| **整套退出** | **齿轮菜单或右键底部状态行** →「退出应用（面板与托盘一并退出）」 |

### 卡片上颜色的意思

| 颜色/标记 | 意思 |
| --- | --- |
| 左侧竖条颜色 | 按开始时间分段（上午/下午/晚上各不同色） |
| 蓝色 `课` 小标 | 这条是课程表里的课 |
| 绿色 `进行中` | 这件事**正在进行**（卡片底下还有一条进度条） |
| 灰色卡片 | 已经过去的 |
| 红色 `日期待确认` | 通知里没写日期，只能按粘贴当天归档（**请自己核对**） |

### 面板不会因为什么而消失

- 点任务栏右下角"显示桌面"、按 `Win+D` → **不消失**（面板会浮到普通窗口之上）
- 有全屏应用（游戏/视频）→ 临时隐身，退出全屏自动回来（**这是故意的**，不挡画面；想要一直显示就切到「常驻待机」）
- 仅在**手动收起**或**在控制台点击「关闭面板」**后才会隐藏

## 4. 把课表导进来

控制台 →「课程表」页，四条路：

### 4.1 从文件识别（推荐）

点击 **「从文件识别课表…」**，支持多选。格式如下：

| 后缀 | 从哪来 | 说明 |
| --- | --- | --- |
| `.ics` | WakeUp 课程表 → 导出 | **最准确**：含绝对日期，星期与节次无需推断 |
| `.pdf` | 教务系统打印/导出课表 | 按 ★ 定位课程格 |
| `.html` `.htm` | 课表页"另存为" | |
| `.csv` `.tsv` | Excel / WakeUp 模板 | 能识别列名即可 |
| `.json` | 本程序自己的 timetable.json | |
| `.txt` `.md` | 复制出来的课表文本 | |

### 4.2 确认识别结果（**这一步很重要**）

识别结果不保证完全准确，因此**不会直接覆盖**，而是先弹出确认窗口供核对：

| 能做的事 | 怎么操作 |
| --- | --- |
| 改任意一格 | **双击**那个格子就地改（星期是下拉框，选错会自动退回） |
| 删掉一行 | 选中行按 `Delete`，或点「删除所选」 |
| 补一行 | 点「新增一行」 |
| 重新解析 | 点击「重新识别」 |
| 放弃 | 点「取消」或按 `Esc` —— 课表**一个字都不会变** |

窗口上方有个 **「第 1 教学周周一」** 输入框，**周次是按它算的**。如果教务上写"第4周"而这里算成"第3周"，改这一个框就对齐了，比逐条改 18 行便宜。填非周一会自动校准到那一周的周一。

### 4.3 粘贴课表

「粘贴课表…」：从 Excel / WPS / 网页 / 教务复制的**表格文本或整页 HTML** 都认，走同一个确认窗。

### 4.4 手动增删改

- 「新增课程」：填课程名、星期、节次（如 `3-4`）、地点、老师、周数
- 课程列表中**双击**任一条即可修改（窗口内已带出该课程原有内容，
  仅需改动目标字段；星期填 `1`~`7`，1 表示周一）
- 选中后按 `Delete` 删除
- 「清空课程表」清空全部（会自动备份，随时能「撤销上次导入」）

### 4.5 导出回手机

「导出 WakeUp CSV」生成 WakeUp 课程表官方模板，发到手机上用它自带的「excel导入」打开。

### 周次怎么写

| 写法 | 意思 |
| --- | --- |
| `1-16` | 第 1 到 16 周每周 |
| `1-5、7-11单` | 1~5 周 + 7~11 周的**单周** |
| `2-8双` | 2~8 周的**双周** |
| 留空 | 每周都有 |

## 5. 把群通知加进来（四种方式）

### 方式一：把消息文件拖到面板上（最省事）

把 QQ 导出的消息保存成 `.txt`，**直接拖到桌面面板上**：

- 底部会显示「通知 N 条新增」
- 时间线立刻刷新
- 拖**整个文件夹**也行，会递归找里面的文本文件
- 拖入 `.ics` / `.pdf` → 按课表识别
- 拖入其他文件 → 底部提示无法识别，不做任何改动

QQ 导出的文件常是 GBK 编码，**也认**。

### 方式二：粘贴（最直接）

在控制台「通知」页粘贴至输入框 → 约 1 秒后自动识别，下方显示结果 → 点击 **「保存并刷新」**。

- 一次可以粘**多条**，用空行或 `[群名]` 开头分隔
- 「来源群名」可填可不填（通知里写了 `[群名]` 就以它为准）
- 填完后按 `Ctrl+Enter` 也能保存

### 方式三：快速录入窗

在面板空白处右键 →「快速录入群消息…」，粘贴后点击「保存并解析」。效果同方式二，且无需切换窗口。

### 方式四：收件箱（批量/自动）

把 `.txt` 文件丢进 `data\inbox\`，然后：

- 等面板自动整合（默认每 15 分钟）
- 或右键面板 →「立即整合群通知」
- 或跑一次 `run-daily.cmd`（计划任务每天早上 7:30 跑的就是它）

处理过的文件会自动移到 `data\archive\`。
> 注意：文件名里带 `示例`/`demo`/`sample`/`test` 的**会被跳过**（防止演示文件被当成真通知抓进来）。

### 通知怎么写才认得出

写全这四样就非常准：

```
[群名]
通知：9月25日 14:00-15:30 在3号楼201会议室召开班级例会，负责人：张伟老师，请携带笔记本。
```

| 字段 | 支持的写法 |
| --- | --- |
| **日期** | 今天 / 明天 / 后天 / 这周五 / 下周三 / 周五 / 9月25日 / 9/25 / 2026-09-25 |
| **时段** | 14:00-15:30、14点到15:30、下午3点到5点、上午9点、**今天中午12:00前** |
| **地点** | 在3号楼201会议室、实验楼B302、三教302、腾讯会议、学术报告厅、线上 |
| **人员** | 负责人：张伟老师、@王强、联系人：陈静、由X负责 |
| **备注** | `备注：…`、`请携带…`、`请提前…` 后面的整句 |

**认不出的情况**：完全没写日期的，按粘贴当天归档并标红「日期待确认」——不猜。

## 6. 处理单条日程：右键

**右键面板上的某一张卡**（或控制台「通知」页下方列表里的某一行）：

| 菜单项 | 做什么 |
| --- | --- |
| **标记为已完成** | 事办完了，这条从日程里消失，面板立刻刷新 |
| **修改结束时间…** | 弹出小窗，**时 / 分各一个下拉框**（无需输入冒号），修改后立即生效 |
| **复制内容** | 标题 / 时间 / 地点 / 人员 / 备注一行进剪贴板 |
| **删除此条…** | 彻底删除（会先确认一次） |

几个细节：

- **通知**：改结束时间直接写进 `events.json`；标记为已完成或删除即从日程中移除
- **课程**：改结束时间只给**这一条**记一个覆盖值，**不改动全校课时表**（课时表是作息安排，改动会影响所有课程）
- 面板**空白处**右键为全局菜单；卡片右键为该条目的菜单；**底部状态提示那一行**右键为
  「打开客户端窗口 / 快速录入群消息… / 立即整合群通知 / 刷新界面 / 收起面板 / **退出应用**」——如需整体退出（含托盘）
  请选择最后一项

**撤销**：删除不可撤销，但每次导入课表都会自动留备份，可使用「撤销上次导入」。
通知删了想要回来，得从 `data\archive\` 里的原始文件重新整合一次。

## 7. 上课时间与节数

控制台 →「上课时间」页。

| 项 | 说明 |
| --- | --- |
| **一共几节课** | 1~24 节，改完点「套用节数」，下面的输入框会重排（**已填的时间会带过去**） |
| 每节的**开始 / 结束** | 时、分各一个下拉框，中间的 `:` 为标签，**无需输入** |
| **学期开始（第 1 周周一）** | 三段式日期输入（短横线不可删除）；周次按它算；填成非周一会被提示并自动校准 |
| **保存课时** | 保存并让面板按新时间重排 |
| **恢复默认时间** | 回到内置课时（超过 12 节的部分按"45 分钟一节 + 10 分钟课间"往下顺延） |
| **每节课时长相同** | 按第一节的时长把后面每节推平 |

写错了会被拦住：下课时间不早于上课时间、中间不能空一节（末尾空行按"没配到那一节"处理，不算错）。

## 8. 假期、调休与节日彩蛋

控制台 →「假期」页。这一页解决三件事：**放假不排课**、**调休要补课**、**过节有点气氛**。

### 8.1 假期：这段时间不排课，但群通知照收

| 字段 | 说明 |
| --- | --- |
| 名称 | 比如 `国庆节`。**名字要和节日对得上**，节日彩蛋才知道这几天是一伙的 |
| 开始 / 结束 | 三段式日期输入：年、月、日各自一格，**中间的短横线是分隔符，删不掉**（只能填数字，年满 4 位自动跳到月、月满 2 位跳到日） |

在假期区间里，面板**一门课都不排**，但**群里的通知照常显示**——放假期间老师照样发通知，
这条是特意要的。日期头上会写「今天 10/2 周五 · 国庆节假期（还剩 7 天）」，右边标「假期」。

假期表里有一列 **状态**：`未开始` / `进行中` / `收尾中` / `已结束`。假期到点**自动失效**
（不再压课、不再改日期行），不需要你手动去删；历史条目可以用「清理已结束」一键收掉。

四个按钮：

| 按钮 | 做什么 |
| --- | --- |
| **新增假期** | 手动加一段；双击表格里的行也能改 |
| **按节日预填…** | 按「节日当天 + 常见连休天数」铺一份**草稿**（元旦 1 天、春节 8 天、国庆 7 天……）。**该结果为推算，务必以学校通知为准**，生成后请在表中核对 |
| **从放假通知识别…** | 粘贴学校或国务院的放假通知**原文**，自动识别假期区间与调休日 |
| **清理已结束** | 把已经过去（含收尾期）的假期从表里删掉；调休记录不受影响 |

> 为什么假期日期不写死在程序里？每年的放假安排是国务院另外发的通知，
> 还会因为凑假年年不同。所以这里给的是"工具 + 草稿"，事实以你的学校通知为准。

### 8.2 假期结束后的收心倒计时

假期一结束，面板自动回到正常排课；**紧接着的三天**会在日期下方多一条小提示，按天数递减：

```
✦ 国庆节假期已结束 · 收心倒计时 3 天     ← 假后第 1 天
✦ 国庆节假期已结束 · 收心倒计时 2 天     ← 第 2 天
✦ 国庆节假期已结束 · 收心倒计时 1 天     ← 第 3 天
```

第四天起这条提示自动消失，假期状态也彻底结束（状态列变成「已结束」）。

### 8.3 调休：那一天补哪一天的课

调休窗是"一行一组"的：左边**调休日**（当日需上课），右边**补课日期**（补哪一天），两个都是
三段式日期控件；要多天就点「添加一行」，一行只对应一天。

例：`10月10日（周六）补 10月7日（周三）的课` → 调休日填 `2026-10-10`、补课日期填 `2026-10-07`。

面板那天的日期旁边会多一行**小字**：

```
今天 10/10 周六   调休10月7日日程        4 节课
```

课程按**被补的那一天**（周三）排，包括单双周、第几周这些规则都按那一天算。
小字也能自己改（窗里那一栏），留空就是默认的「调休X月X日日程」。

### 8.4 节日彩蛋

**触发条件**（三档，越靠前优先级越高）：

1. **节日当天**；
2. `data\calendar.json` 里**同名的假期区间内**（所以国庆 10/1–10/8 整段都有气氛）；
3. **节日前后各 3 天**（比如中秋 9/25，9/22 起面板就进入节日状态）；
4. 假期刚结束的**收尾期**（上面那三天倒计时）里也会保留。

有彩蛋的日子，面板顶部会多一条横幅：节日配色、装饰动画与一句祝福语，横幅下方提示「点击横幅查看节日寄语」，
**点击**才展开该节日的彩蛋文案（再点一次收起）。节前会写「还有 N 天」，收尾期会写「收心倒计时 N 天」。

**面板边框也会跟着节日走**：平时是 1px 细边，节日期间换成节日主色、加粗到 3px，并且缓慢"呼吸"。

| 节日 | 气氛 | 彩蛋里有什么 |
| --- | --- | --- |
| **元旦** | 烟花次第绽放 | 岁首提示：先览课表，再续前岁未竟之事 |
| **春节** | 红灯笼轻轻晃、金屑飘落 | 春节期间课程停排、群通知照常汇总 |
| **元宵节** | 灯笼 + 一轮圆月 | 正月十五，岁节之末 |
| **清明节** | 细雨 + 抽芽的柳枝 | 清明前后多雨，出门备好雨具 |
| **劳动节** | 齿轮慢慢转 | 劳动节源于争取八小时工作制，宜充分休息 |
| **端午节** | 龙舟 + 水波 | 观龙舟、食角黍皆为节俗 |
| **中秋节** | 月亮升起、薄云、疏星 | 但愿人长久，千里共婵娟 |
| **国庆节** | 五角星 + 飘动的旗 | 祝祖国繁荣昌盛；返校前核对是否设有调休 |

彩蛋的日期覆盖 **农历 1900–2100 年**（春节、元宵、端午、中秋按农历推算，清明按节气推算，
由随程序附带的农历库计算）。超出该范围的年份不会推测日期，而是安静地不触发彩蛋。

### 8.5 面板上跟日期有关的两处

- 顶部日期行**带年份**：`2026年9月25日 周五 · 第 3 教学周`，节日当天还会染成节日色
- 跨年期间（如 1 月 1 日在一周之后），日期头写成 `2027/1/1`，年份一目了然

## 9. 设置项逐个说明

控制台 →「设置」页。**这一页刻意做得很短**：只留日常真正会调的几项，其余都有稳妥的默认值。

| 设置 | 说明 | 建议 |
| --- | --- | --- |
| **启动时显示桌面面板** | 下次启动是否自动拉起面板 | 开 |
| **到点弹窗提醒** | 事项开始前弹一个小窗 | 开 |
| **关闭本窗口时** | 固定行为：最小化至托盘，**桌面面板继续显示**（不可改） | — |
| **待机模式** | **智能隐身** = 检测到全屏应用（游戏/视频）时自动让位，切回桌面立刻恢复；**常驻待机** = 全屏运行其他应用时面板也不隐藏，始终留在屏幕上（见 [第 10 节](#10-待机模式面板什么时候让位)） | 智能隐身 |

改完后点「保存设置」，会问你要不要立刻重启面板（待机模式要重启才生效）。

**页脚常驻**：数据目录路径，以及说明「课表导入仅读取所选文件，不联网、不需要账号密码」。

**页脚下方常驻入口**：
- **📖 查看使用教程** —— 就是这份文档，随时点开、可搜索
- **打开数据目录** —— 直接跳到 `data\`
- **定位教程文件** —— 在资源管理器里选中 `docs\教程.md`

> **进阶开关不在界面上**：自动整合间隔、面板图层（`window_mode`）、鼠标穿透、桌面宠物模式
> 这几项默认值已经适合绝大多数人，所以从界面上拿掉了。真要改，直接编辑 `data\client.json`
> （字段名见 `agenda\client_config.py`），或用命令行开关
> （`--window-mode topmost` / `--always-visible` / `--no-click-through` / `--no-pet-mode`）。

## 10. 待机模式：面板什么时候让位

**待机模式**（设置里二选一）决定"全屏应用在前台"时面板怎么办：

| 模式 | 行为 |
| --- | --- |
| **智能隐身**（默认） | 检测到全屏应用（游戏/视频）时把面板让出去；切回桌面立刻恢复。面板按定时器持续刷新 |
| **常驻待机** | 全屏运行其他应用时面板**不隐藏**，始终留在屏幕上（双屏、或者就想一直看着的人选它） |

| 操作 | 面板行为 |
| --- | --- |
| 查看桌面 / 按 `Win+D` / 点击任务栏「显示桌面」 | **浮于普通窗口之上**，清晰可见（宠物模式） |
| 打开其他窗口 | 正常被覆盖，不干扰工作 |
| 开全屏游戏或全屏视频 | **智能隐身**下自动让位；**常驻待机**下不受影响，始终显示 |
| 切回桌面 / 解锁屏幕 / 显示器重新点亮 | **几乎立刻**回来（40 ms 轮询 + 系统唤醒消息即时触发；实测平均 40 ms） |
| 面板被最小化（极少数情况） | 自动还原；正常情况下它**根本不可能被最小化** |

面板不是 always-on-top 窗口，所以它不会压在游戏上面。想让它总在最前，把 `data\client.json`
里的 `"window_mode"` 改成 `"topmost"`（或加命令行开关 `--window-mode topmost`）后重启面板。

## 11. 窗口找不到了怎么办

### 关闭控制台 ≠ 关闭日程表

点控制台右上角的 `X` **只会把控制台最小化至托盘**：桌面面板继续显示，通知照收、到点提醒照弹。
（第一次关的时候会提示一次"去哪儿完全退出"，之后不再打扰。）

**完全退出**只有两个入口，都会把面板和托盘一起退干净：

| 入口 | 位置 |
| --- | --- |
| **退出应用** | 托盘图标右键 →「退出应用」 |
| **退出应用（面板与托盘一并退出）** | 面板右下角 **⚙ 齿轮** → 最后一项（或右键底部状态行） |

> 反过来也成立：在面板上右键「收起面板」只收起面板，控制台和托盘不受影响。

### 控制台不见了

它可能已被最小化至托盘（窗口隐藏，进程仍在运行）。以下三种方式均可唤回：

| 方式 | 说明 |
| --- | --- |
| **再双击一次桌面快捷方式 / `start-client.cmd`** | 会通知已经在跑的那个实例把窗口显示出来 |
| **双击托盘图标** | 托盘双击的默认动作就是「呼出客户端窗口」 |
| **面板右下角 ⚙ 齿轮 →「打开客户端窗口」** | 万一托盘图标找不到，从面板也能叫回来；齿轮还能直接跳到「设置」页 |

### 托盘图标右键菜单

任务栏右下角那个图标上**右键**：

| 菜单项 | 做什么 |
| --- | --- |
| **呼出客户端窗口** | 把控制台叫到最前面（和双击图标一样） |
| **快速录入群消息…** | 叫出控制台、切到「通知」页、光标直接落在输入框里，粘上就能存 |
| **打开桌面面板 / 收起桌面面板** | 开关桌面那个日程面板 |
| **立即整合群通知** | 立即执行一次 inbox 整合，无需等待下一轮 |
| **退出应用** | 面板 + 托盘一起退干净 |

### 面板不见了

| 情况 | 处理 |
| --- | --- |
| 有全屏应用在前台 | 正常行为（智能隐身在起作用），切出来立刻回来 |
| 曾手动收起 | 在控制台点击「打开面板」，或托盘右键 →「打开桌面面板」 |
| 面板进程确已退出 | 在控制台点击「打开面板」（会重新启动进程） |
| 就是不出来 | 命令行：`runtime\python.exe main.py --status --width 360` 看看它认为该显示什么；或删掉 `data\panel_x/panel_y` 相关字段重新定位 |

## 12. 数据在哪、怎么备份、怎么恢复

全部在 `data\` 目录，**都是可读的 JSON**：

| 文件 | 是什么 |
| --- | --- |
| `events.json` | 一周内的通知（日程本体） |
| `timetable.json` | 课程表 + 课时表 + 学期开始 |
| `calendar.json` | 假期区间 + 调休（在「假期」页里改，也可以直接手写） |
| `client.json` | 客户端设置 |
| `state.json` | 上次整合的时间与摘要 |
| `inbox\` | 待整合的群消息文件（丢这里就会被处理） |
| `archive\` | 已整合过的原始文件 |
| `browser-profile\` | 独立浏览器配置（拖放/排错用，删掉没影响） |
| `panel.log` | 面板出错时的日志（**正常时是空的**） |

**备份**：整个 `data\` 目录拷走就是完整备份。
**恢复**：拷回来覆盖即可。
**清理**：删除 `events.json` 即清空通知；删除 `timetable.json` 即清空课程表（面板显示「暂无日程安排」）。

**自动备份**：每次导入/保存课表都会写 `timetable.json.bak`，控制台的「撤销上次导入」用的就是它。清空通知会另存 `events.cleared-<时间>.json`。

## 13. 常见问题

| 现象 | 处理 |
| --- | --- |
| **客户端打不开** | 程序仍在运行，只是窗口已隐藏：再次双击快捷方式即可唤回（见 [第 11 节](#11-窗口找不到了怎么办)） |
| 面板点不动 | 极少数情况是 `data\client.json` 里 `"click_through"` 被手改成了 `true`，改回 `false` 后重启面板 |
| 面板被其他窗口遮挡 | 属正常现象（面板位于桌面层）；如需始终在前，把 `data\client.json` 的 `"window_mode"` 改成 `"topmost"` |
| 清空屏幕（`Win+D`）后面板消失 | 检查 `data\client.json` 里的 `"pet_mode"` 是不是被改成了 `false`（默认 `true`，即不会被压掉） |
| 游戏里被挡 | 设置 → 待机模式 → 选「智能隐身」 |
| 放假了课表还在排课 | 控制台 →「假期」页加一段假期；或粘放假通知让它自己认 |
| 调休那天显示的是平时的课 | 「假期」页加一条调休：调休日 + 补哪天的课 |
| 节日当天无彩蛋 | 节日当天必定出现；若希望**整个假期**都有，请配置假期区间（名称需与节日一致） |
| 选的文件提示「未能识别课表」 | 命令行看一眼：`runtime\python.exe -m agenda.file_import 你的文件`，会打印读取到的内容与失败环节 |
| 周次与教务不一致 | 在确认窗口上方修改「第 1 教学周周一」（见 [4.2](#42-确认识别结果这一步很重要)） |
| 读到的课缺教师/地点 | 确认窗里双击补上；也欢迎把文件发我加规则 |
| 通知的标题粘了半句话 | 已修：现在会在「事项名：说明」的冒号处截断。仍有问题就把原文发我 |
| 拖入文件无反应 | 请确认拖入的是文件或文件夹（而非选中的文字）；其他内容会提示无法识别 |
| 面板滚动卡顿 | 已优化（卡片控件复用）。若仍有卡顿，请反馈通知数量 |
| 需要适配其他学校 | 先运行 `runtime\python.exe tools\probe_schools.py` 查看该校入口形态 |

## 14. 命令行参数

一般用不到，排错和自动化时有用（`runtime\python.exe` 是项目自带的 Python）：

```powershell
runtime\python.exe main.py --client --start-panel   # 客户端 + 面板
runtime\python.exe main.py --tutorial               # 打开这份教程
runtime\python.exe main.py --status                 # 命令行看一周日程（含假期/调休/节日）
runtime\python.exe main.py --once                   # 整合 inbox 一次
runtime\python.exe main.py --check-timetable        # 逐条列出读到的课
runtime\python.exe main.py --paste --group 班群      # 从 stdin 粘一条通知
runtime\python.exe main.py --list-schools           # 看已登记的学校
runtime\python.exe -m agenda.file_import 课表.ics    # 单独测试文件识别
runtime\python.exe -m unittest discover -s tests -t .   # 跑测试
```

其它有用的开关：`--width`、`--refresh`、`--pipeline-minutes`、`--window-mode`、
`--no-click-through`、`--always-visible`、`--no-pet-mode`、`--panel-x/--panel-y`、`--data-dir`。
