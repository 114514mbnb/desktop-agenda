桌面日程 v1.1：假期调休与节日彩蛋、界面精简、开源准备

一个 Windows 桌面日程面板：把 QQ 群通知和课程表合并成常驻桌面右侧的时间线。
v1.1 在 v1.0 的基础上补完了「学期里真正会遇到的日历问题」，并把界面收拾干净。

新增
- 假期 / 调休：在控制台「假期」页加区间，假期内一天课都不排（群通知照旧显示），
  调休日按「补哪一天的课」重放课表；也能直接粘一条放假通知让它自己认。
- 节日彩蛋：元旦 / 春节 / 元宵 / 清明 / 劳动 / 端午 / 中秋 / 国庆 八个节日，
  当天横幅换成节日主题，点开有寄语与动画彩蛋；跨年日历头带年份。
  日期由随程序附带的农历库推算，覆盖农历 1900–2100 年。
- 假期收尾：假期结束后不再显示「已过 N 天」，改为按天数的收心倒计时。
- 待机模式二选一：**智能隐身**（全屏应用时自动让位，切回桌面立刻恢复）/
  **常驻待机**（全屏时也不隐藏）。
- 恢复速度：前台状态 40 ms 快查 + 解锁/亮屏/分辨率变化由系统消息即时唤醒
  （实测从 102 ms 降到 40 ms；解锁那条路是当帧恢复）。
- 日期输入框：年/月/日三个格子、分隔符删不掉，专治「- 被删掉后日期变成一串数字」。

界面
- 设置页只留日常会调的四项（启动显示面板 / 到点弹窗 / 待机模式 / 数据目录），
  整合间隔、窗口图层、鼠标穿透、宠物模式改为配置默认值，要改请编辑 data/client.json。
- 面板右下角新增齿轮按钮：日程表设置… / 打开客户端 / 快速录入 / 立即整合 / 刷新 / 收起 / 退出应用。
- 移除面板底部的技术细节行（课表路径等），底部只留业务信息。

工程
- 全部界面文案改为书面文体，去掉口语化表达（面向第三方用户）。
- 新增 agenda/lunar.py 与内置农历库（vendored，MIT），假日日期不再靠硬编码表。
- 修一个正方课表解析的真 bug：`中心校区 D-107 周宏` 里 `107 周` 被当成"周次"，
  整行判成纯周次行直接丢掉，教师和地点一起消失（姓周的老师 + 教室号才会触发）。
- 测试 370 项（含新增的界面精简 / 齿轮入口 / 退出应用 / 农历 / 假日 / 彩蛋 UI 回归）。

开源前的隐私清理（这次出包的重头）
- 仓库里原本带着大量**真实个人数据**：`tests/fixtures/wakeup-sample.ics` 是本人从
  WakeUp 导出的完整课表，测试与文档里散落着真实教师姓名、教室号、班级代号、QQ 群名，
  `paste-notice.cmd` 里还有本机用户名路径，README 头图与节日效果图全部截自真实课表。
- 现在：所有真实姓名/教室/校区/班级代号/本机路径统一替换成同结构虚构值；
  截图工具改为只读 `tools/demo_data.py`（虚构数据），不再 `shutil.copy(data/timetable.json)`；
  出包脚本改成"data/ 白名单"，修掉 `calendar.json`（放假区间 + 调休）被一起打进 zip 的泄漏。

一如既往
- 零第三方运行时依赖：只用标准库 + tkinter，自带 python-build-standalone 运行时。
- 数据全是明文 JSON；不登录任何系统、不接触账号密码、不联网。
